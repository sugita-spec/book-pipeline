# 営業リスト — BOOK PIPELINE

BOOK☆WALKER の指定一覧から書名・配信開始日・著者を取得し、著者の公開プロフィールで確認した勤務先の公式 URL・会社電話・Facebook・Instagramを紐づける営業用ダッシュボードです。

各書籍の「DMをコピー」ボタンで、著者名・書名を差し込んだ「生×カラ！TV」出演オファー文をクリップボードへコピーできます。差出人名と連絡先はブラウザ内に保存され、送信はInstagramで内容を確認して手動で行います。

## 起動

```bash
pnpm install
pnpm dev
```

- Web: `http://127.0.0.1:4173`
- API: `http://127.0.0.1:4174`

本番ビルド後は `pnpm build && pnpm start` で `http://127.0.0.1:4174` から配信します。

## Cloudflare Workersへ公開

Cloudflare WorkersではViteの静的アセットと `/api/books` を同じWorkerから配信します。

```bash
npm run deploy
```

- `wrangler.jsonc` が公開設定の正本です。
- `/api/books` はCloudflareのエッジで15分キャッシュします。
- 最新情報を取得できない場合は `server/cache.json` の保存済みデータを表示します。

## データ更新

- 初回表示と「最新情報に更新」操作で BOOK☆WALKER を取得します。
- 書籍詳細ページから「配信開始日」を補完します。
- 取得負荷を抑えるため、同時取得は6件、成功データは15分キャッシュします。
- 勤務先は著者プロフィールと会社公式情報を照合したローカル台帳を使います。
- Facebook・Instagramは本人と確認できた公開アカウントだけを表示します。
- 勤務先を公開情報で確認できない著者は、推測で補わず「未確認」と表示します。

> 勤務先や電話番号を推測で埋めないため、公開情報がない場合は「未確認」「公開なし」になります。
